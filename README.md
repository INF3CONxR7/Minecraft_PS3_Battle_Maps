## Installation

1. Téléchargez l’archive de la carte dans la [dernière version](https://github.com/INF3CONxR7/Minecraft_PS3_Battle_Maps/releases/latest).
2. Décompressez-la, puis copiez son dossier `PS3` à la racine d’une clé USB formatée en FAT32.
3. Sur la PS3 : **Jeu > Utilitaire de données sauvegardées (PS3) > Périphérique USB**, puis copiez la sauvegarde de votre
   version du jeu.
4. Lancez Minecraft et chargez le monde : il porte le nom de la carte.

Chaque archive contient aussi un `LISEZ-MOI.txt` qui reprend ces étapes pour sa carte.

## À savoir

- **Créatif** : terrain, constructions, coffres et entités sont identiques à la carte d’origine ; la difficulté n’est
  plus verrouillée comme en mode Battle.
- **Coffres vides** : en mode Battle, le jeu remplit les coffres de l’arène à chaque manche.
- **Vérifiées sur ordinateur** avec MCS Studio : signature PS3 de chaque sauvegarde et contenu de la carte.
- **Autre compte** : les sauvegardes ont été créées sur une autre PS3. Si la vôtre en refuse une, re-signez-la pour
  votre compte (avec Apollo Save Tool, par exemple).
- **Pas de version japonaise** (`NPJB00539`) pour l’instant : [MCS Studio](https://github.com/INF3CONxR7/MCS_Studio) peut
  la créer à partir de n’importe laquelle de ces sauvegardes.
